## What Claude set up on the site itself (no accounts needed)

- Search engines are told about every page each business day via IndexNow (Bing, Yandex, Seznam, Naver), and the sitemap is published.
- Each product page carries schema.org Product data (name, price, availability) so search results can show the price.
- Canonical links and social-share tags, so links pasted into Facebook, Reddit, X or texts show a proper title and description.
- Google AdSense support is built in but switched off. It turns on when `ads.adsense_client` in config.yaml is set to an approved `ca-pub-…` id. AdSense requires the owner's own Google account and identity, a site on a domain the owner controls (not a github.io sub-path), and Google's approval.
